## 1. Conventions

### 1.1 Authentication
- **Method**: Bearer token (JWT from Supabase Auth)
- **Header**: `Authorization: Bearer <access_token>`
- **Token Claims**: `sub` (user_id), `workspace_id`, `role`, `exp`
- **Workspace Context**: Extracted from token, enforced via RLS

### 1.2 Request/Response Format
- **Content-Type**: `application/json`
- **Request IDs**: `X-Request-ID` (generated by client or gateway)
- **Idempotency**: `Idempotency-Key` header for all mutating endpoints
- **Pagination**: Cursor-based (`cursor`, `limit`, `next_cursor`)

### 1.3 Error Format (RFC 7807)
```json
{
  "type": "https://api.ideaos.com/errors/validation_error",
  "title": "Validation Failed",
  "status": 422,
  "detail": "Request body validation failed",
  "instance": "/api/v1/captures",
  "errors": [
    {
      "field": "type",
      "code": "invalid_enum_value",
      "message": "type must be one of: voice, image, file, link, text"
    }
  ]
}
```

### 1.4 Common HTTP Status Codes
| Code | Meaning |
|------|---------|
| 200 | Success |
| 201 | Created |
| 202 | Accepted (async processing) |
| 400 | Bad Request |
| 401 | Unauthorized |
| 403 | Forbidden |
| 404 | Not Found |
| 409 | Conflict |
| 422 | Validation Error |
| 429 | Rate Limited |
| 500 | Internal Error |
| 503 | Service Unavailable |

### 1.5 Rate Limiting
- **Default**: 100 requests/minute per workspace
- **Headers**: `X-RateLimit-Limit`, `X-RateLimit-Remaining`, `X-RateLimit-Reset`
- **Burst**: 200 requests/10 seconds

## 2. Capture Endpoints

### 2.1 Create Capture
**POST** `/captures`

Initiates a capture. Returns presigned URL for direct upload to object storage.

**Request:**
```json
{
  "type": "voice|image|file|link|text",
  "source_text": "Optional raw text for text/link captures",
  "metadata": {
    "filename": "recording.m4a",
    "mime_type": "audio/m4a",
    "size_bytes": 1024000,
    "duration_seconds": 45,
    "url": "https://example.com/article",
    "selected_text": "Highlighted portion...",
    "page_title": "Article Title"
  },
  "idempotency_key": "client-generated-uuid"
}
```

**Response (201):**
```json
{
  "capture_id": "uuid",
  "status": "uploading",
  "presigned_upload": {
    "url": "https://r2.ideaos.com/bucket/key?signature...",
    "method": "PUT",
    "headers": {"Content-Type": "audio/m4a"},
    "expires_at": "2026-10-31T12:00:00Z"
  },
  "created_at": "2026-10-31T11:55:00Z"
}
```

**Validation:**
- `type` required, must be valid enum
- `metadata` required for file/image/voice (filename, mime_type, size_bytes)
- `size_bytes` ≤ 500MB (configurable)
- `mime_type` must match allowed list per type
- Idempotency key prevents duplicate captures

### 2.2 Complete Asset Upload
**POST** `/assets/complete`

Called after client successfully uploads to presigned URL.

**Request:**
```json
{
  "capture_id": "uuid",
  "checksum": "sha256-hex-string",
  "metadata": {"width": 1920, "height": 1080}
}
```

**Response (200):**
```json
{
  "asset_id": "uuid",
  "capture_id": "uuid",
  "status": "processing",
  "message": "Asset uploaded. Processing started."
}
```

**Processing:**
1. Validates checksum matches uploaded file
2. Creates `asset` record
3. Triggers ingestion job (transcribe/extract/embed)
4. Updates capture status to `processing`

## 11. SDK Usage Examples

### 11.1 TypeScript SDK
```typescript
import { IdeaOSClient } from '@ideaos/sdk';

const client = new IdeaOSClient({
  apiKey: 'sk_live_...',
  baseUrl: 'https://api.ideaos.com/api/v1'
});

// Create capture with file upload
const capture = await client.captures.create({
  type: 'voice',
  metadata: { filename: 'idea.m4a', mime_type: 'audio/m4a', size_bytes: 1024000 }
});

// Upload to presigned URL
await client.assets.upload(capture.presigned_upload.url, fileBlob);

// Complete and trigger processing
await client.assets.complete(capture.capture_id, checksum);

// Poll for idea
const idea = await client.ideas.waitForCompletion(capture.capture_id);

// Get fusion proposals
const proposals = await client.fusion.getProposals(idea.id);

// Generate content
const job = await client.content.repurpose(idea.id, ['instagram_reel', 'linkedin_post']);
const outputs = await client.content.waitForGeneration(job.id);
```

### 11.2 Python SDK
```python
from ideaos import IdeaOSClient

client = IdeaOSClient(api_key="sk_live_...")

# Quick capture
capture = client.captures.create(type="text", source_text="My idea...")
client.assets.complete(capture.id, checksum)

# Wait for processing
idea = client.ideas.wait_for_completion(capture.id)

# Fusion
proposals = client.fusion.get_proposals(idea.id)
client.fusion.approve(proposals[0].id, create_master_idea=True)

# Content
outputs = client.content.repurpose(idea.id, platforms=["linkedin_post"])
```
